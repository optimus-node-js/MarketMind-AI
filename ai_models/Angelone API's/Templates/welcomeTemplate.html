Welcome to the Stock Market Data API

This API allows you to fetch real-time stock data such as Last Traded Price (LTP) and OHLC (Open, High, Low, Close) data. Below are the available endpoints and instructions on how to use them.

Available Endpoints:

  • POST /get_ltp/ - Get the Last Traded Price (LTP) of a stock.
  • POST /get_ohlc/ - Get OHLC data for a stock within a date range.

How to Use:

1. Fetch Last Traded Price (LTP)

Request Type: POST

URL: http://127.0.0.1:8000/get_ltp/

Request Body:

{
    "symbol": "IRFC-EQ",
    "token": "2029"
}

Response Example:

{
    "symbol": "IRFC-EQ",
    "ltp": 123.45
}

2. Fetch OHLC Data

Request Type: POST

URL: http://127.0.0.1:8000/get_ohlc/

Request Body:

{
    "symbol": "IRFC-EQ",
    "token": "2029",
    "interval": "ONE_DAY",
    "from_date": "2023-09-01 09:15",
    "to_date": "2023-09-01 15:30"
}

Response Example:

{
    "symbol": "IRFC-EQ",
    "interval": "ONE_DAY",
    "data": [
        {
            "date": "2023-09-01",
            "open": 120.50,
            "high": 125.00,
            "low": 119.75,
            "close": 123.00
        },
        ...
    ]
}

Notes:

  • Ensure that you replace the symbol and token values with valid stock symbols and tokens.
  • The interval for OHLC can be set to values such as ONE_MINUTE, ONE_DAY, etc.
  • Both endpoints return JSON responses with either the requested data or error details.

Happy Trading!
